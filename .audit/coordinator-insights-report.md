# Coordinator insights handoff

The coordinator-only `/api/insights` and `/insights` projection reads synchronized stored state and checks the current actor again in `InsightsService`. Output is limited to community aggregates and individual community resource availability; it contains no request text, contact details, or request identifiers. The client aborts obsolete requests and gates loaded results by actor identity and role.

Submitted requests include all community requests, including restricted and administratively closed requests. Ever accepted requests include requests with an acceptance timestamp or a status that implies acceptance; active commitments use the existing domain definition. Fully resolved requests require all needs resolved and no administrative closure; confirmed needs count resolved need records separately. Overdue requests exclude closures and require at least one unresolved need past its window. Participation is distinct member helpers with ever-accepted commitments divided by all community members; organizations are excluded from both figures.

The median is based on the earliest recorded acceptance per request, with missing, invalid, or negative histories excluded and separately counted. Capacity is displayed per resource with its category and consumable or concurrent mode; no cross-resource total is calculated. General eligibility uses active state, remaining capacity, freshness, incident readiness, and owner qualification, while actual matching also depends on the request. Demo clock and synthetic resource owners are labeled.

Verification: `npx vitest run tests/analytics.test.ts` passed 4 tests; `npx tsc --noEmit` passed. Tests use in-memory seed state and do not write the application database. The GET endpoint intentionally calls the existing snapshot synchronization, which can reconcile follow-up state as in other read routes. Browser navigation and full application checks remain for integration. Existing malformed history can limit timing samples; resource quantities do not describe standardized physical units.
