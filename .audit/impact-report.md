# Public impact handoff

The public projection counts Riverton's nonrestricted ordinary requests only. Incident-linked, safety-flagged, medical, and missing-person requests are excluded. Submitted includes administrative closures; open excludes closures and fully resolved requests. Confirmed needs and fully resolved requests are separate measures, and no closed request contributes to either. Category counts represent requests containing each category and can overlap.

The response contains counts and category labels only. The page labels demo data fictional and describes account-mode confirmations as self-reported and unverified. The API is dynamic and sends `Cache-Control: no-store`.
