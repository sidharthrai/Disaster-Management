# Error translation audit

Added `errorsSpanish` as a readonly lookup from fixed English API/domain messages to Spanish. Keys preserve the exact English strings so callers can pass `error.message` directly to the translator.

Scope checked: `src/domain`, `src/lib/api.ts`, and the actual runtime-mode module at `src/server/runtime-mode.ts` (the task's `src/server/http/runtime-mode` path does not exist). Included fixed `requireCondition`/`DomainError` messages, the API generic failure fallback, the intake provider fallback warning, and selected fixed event descriptions emitted through domain services.

Dynamic content, user-authored descriptions/notes/messages, validation text generated by schemas, and provider/model exception text are not translated by this catalog. Runtime configuration messages are included because they can surface as raw API/server errors, though they are primarily operator-facing.

This audit is source-based; no build, server, or tests were run, per task scope.
