# English and Spanish presentation

The local language preference starts in English for server rendering and the first client render, then restores a valid English or Spanish preference from local storage. Storage failures leave the in-memory selector usable. The document language updates after hydration and when the preference changes. Multiple language selectors have unique label IDs.

The shared dictionary combines navigation and intake translations with the independently maintained everyday, operations, account workflows, map, design, and fixed-error dictionaries. Unknown keys fall back to the English key. The new disaster workflow screens `disaster-hub.tsx`, `disaster-people.tsx`, and `disaster-support.tsx` use English fallback where translations are unavailable because their translation was deferred. Source, category, urgency, and other canonical values remain unchanged in application data. User-submitted text and generated content may remain in their original language; the intake screen warns that analysis may not understand Spanish and requires review. Optional browser speech input appends final segments to the editable draft without triggering analysis or submission. Actor changes remount the voice control, and busy or identity-changing states disable it. A separate scoped review confirmed the draft-preserving append and speech disclosure.

Verification: `npx vitest run tests/translations.test.ts` passed four tests after adding the disaster-screen exceptions, and `npx tsc --noEmit --incremental false` passed. Earlier, the five-file translation, speech, and intake suite passed 28 tests. The literal-key coverage check requires Spanish dictionary entries for supported localized client components and all canonical categories, with an explicit exception for those three disaster screens. It checks that those keys exist in the Spanish dictionary; it does not detect unwrapped visible text, dynamically constructed keys, or untranslated user and model content. Browser interaction, live microphone recognition, and end-to-end language coverage were not verified in this scope. The test runner reports an existing Vite configuration warning.
